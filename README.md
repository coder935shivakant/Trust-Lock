# 🔒 TrustLock - Decentralized Escrow & Integrity Protocol

**TrustLock** is a decentralized, non-custodial blockchain escrow platform that enables trustless transactions between unknown buyers and sellers. Built on smart contracts, TrustLock eliminates the need for central intermediaries while integrating real-world logistics tracking, DeFi yield automation, and multi-language accessibility.

---

## ✨ Key Features

- 🔐 **Smart Contract Vault:** Lock funds securely in EVM-compatible smart contracts until all transaction conditions are met.
- 🚚 **Chainlink Oracle Integration:** Automated parcel status updates from real-world logistics providers (DHL, FedEx).
- 💰 **DeFi Yield Automation (Aave v3):** Locked escrow funds earn real-time interest, which is split 50/50 between buyer and seller upon deal completion.
- ⚖️ **DAO Community Dispute Court:** Decentralized voting system for fair dispute handling with multi-language evidence submission via IPFS.
- 🎖️ **Decentralized Reputation (Soulbound Tokens):** On-chain non-transferable badges (ERC-5114) to verify user credibility and trust score.
- 🌐 **Multi-Language Support:** Fully localized user experience in **English** and **Top 10 Indian Languages** (Hindi, Bengali, Marathi, Telugu, Tamil, Gujarati, Kannada, Malayalam, Punjabi, Odia).
- 🎓 **Kids & Beginner Blockchain Academy:** Interactive hash tools and visual lessons to learn smart contract fundamentals safely.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Lucide Icons
- **Blockchain / Web3:** Solidity, Ethers.js / Viem, Web Crypto API (SHA-256)
- **Oracles & DeFi:** Chainlink Data Feeds, Aave v3 Protocol
- **Storage & Identity:** IPFS (Evidence Hash Storage), Soulbound Tokens (ERC-5114)
- **Localization:** Custom i18n Translation Engine
